# Модуль `Config <bonobo.config>`

**Модуль:** `bonobo.config`

Этот модуль предоставляет конфигурационные классы и дескрипторы для настройки преобразований Bonobo.

Основные компоненты:

* `Configurable` — базовый класс для конфигурируемых преобразований
* `Option` — дескриптор для определения опций конфигурации
* `Service` — дескриптор для внедрения сервисов
* `ContextProcessor` — декоратор для контекстных процессоров
* `use` — декоратор для внедрения зависимостей

Подробная документация доступна в исходном коде модуля.
