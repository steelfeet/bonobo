# Модуль `Execution Contexts <bonobo.execution.contexts>`

**Модуль:** `bonobo.execution.contexts`

Этот модуль предоставляет классы контекстов выполнения для узлов и графов Bonobo.

Основные классы:

* `NodeExecutionContext` — контекст выполнения для отдельного узла
* `GraphExecutionContext` — контекст выполнения для всего графа

Эти контексы управляют жизненным циклом выполнения, обработкой ошибок, статистикой и другими аспектами выполнения.

Подробная документация доступна в исходном коде модуля.
