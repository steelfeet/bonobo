# Модуль `Execution <bonobo.execution>`

**Модуль:** `bonobo.execution`

Этот модуль предоставляет функциональность выполнения графов Bonobo, включая стратегии выполнения, контексты и обработку событий.

Основные компоненты:

* Стратегии выполнения (execution strategies)
* Контексты выполнения (execution contexts)
* Обработчики событий (event handlers)

Подробная документация доступна в исходном коде модуля.
