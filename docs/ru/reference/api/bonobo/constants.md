# Модуль `Constants <bonobo.constants>`

**Модуль:** `bonobo.constants`

Этот модуль предоставляет константы, используемые в Bonobo.

Основные константы:

* `NOT_MODIFIED` — специальное значение, указывающее, что данные не были изменены
* `INHERIT` — специальное значение для наследования поведения
* `BEGIN` — специальный маркер начала графа
* `END` — специальный маркер конца графа

Подробная документация доступна в исходном коде модуля.
