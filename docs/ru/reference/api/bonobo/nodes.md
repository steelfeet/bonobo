# Модуль `Nodes <bonobo.nodes>`

**Модуль:** `bonobo.nodes`

Этот модуль предоставляет встроенные узлы (преобразования) для использования в графах Bonobo.

## Категории узлов

### Средства чтения (Readers)
* `CsvReader` — чтение CSV-файлов
* `JsonReader` — чтение JSON-файлов
* `LdjsonReader` — чтение LDJSON (Line Delimited JSON) файлов
* `PickleReader` — чтение Pickle-файлов
* `FileReader` — чтение текстовых файлов

### Средства записи (Writers)
* `CsvWriter` — запись в CSV-файлы
* `JsonWriter` — запись в JSON-файлы
* `LdjsonWriter` — запись в LDJSON файлы
* `PickleWriter` — запись в Pickle-файлы
* `FileWriter` — запись в текстовые файлы

### Преобразования данных
* `Filter` — фильтрация строк на основе предиката
* `Limit` — ограничение количества строк
* `FixedWindow` — создание фиксированных окон данных
* `RateLimited` — ограничение скорости обработки
* `MapFields` — отображение полей
* `Rename` — переименование полей
* `SetFields` — установка значений полей
* `OrderFields` — упорядочивание полей
* `Format` — форматирование данных
* `UnpackItems` — распаковка элементов

### Утилиты
* `PrettyPrinter` — красивый вывод данных в консоль
* `Tee` — разветвление потока данных
* `count` — подсчёт строк
* `identity` — тождественное преобразование
* `noop` — отсутствие операции

Подробная документация доступна в исходном коде модуля.
