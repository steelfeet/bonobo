# Модуль `Graphs <bonobo.structs.graphs>`

**Модуль:** `bonobo.structs.graphs`

Этот модуль предоставляет класс `Graph`, который является основной структурой данных для определения пайплайнов преобразования в Bonobo.

Основной класс:

* `Graph` — класс для создания и управления ориентированными ациклическими графами преобразований

Основные методы класса Graph:

* `add_chain(*nodes, **kwargs)` — добавляет цепочку узлов в граф
* `add_node(node, **kwargs)` — добавляет узел в граф
* `add_outputs(node, *outputs)` — добавляет выходные связи для узла

Подробная документация доступна в исходном коде модуля.
