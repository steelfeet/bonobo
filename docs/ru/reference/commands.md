# Командная строка

## Bonobo Convert

Создаёт простой граф bonobo с одним средством чтения и одним средством записи, затем выполняет его, позволяя использовать bonobo в режиме "без кода" для простых преобразований формата файлов.

Синтаксис: `bonobo convert [-r reader] input_filename [-w writer] output_filename`

## Bonobo Inspect

Инспектирует исходные файлы графов bonobo. На данный момент поддерживает только вывод graphviz.

Синтаксис: `bonobo inspect [--graph|-g] filename`

Требует graphviz, если вы хотите сгенерировать фактическую картину графа, хотя сама команда не зависит ни от чего.
