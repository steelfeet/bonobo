# Примеры

С **bonobo** поставляется несколько примеров.

Вы найдёте их в пакете `bonobo.examples`, и можете запустить их напрямую как модули:

```shell-session
$ bonobo run -m bonobo.examples.module
```

или

```shell-session
$ python -m bonobo.examples.module
```

## Наборы данных

Пакет `bonobo.examples.datasets` содержит примеры, которые генерируют наборы данных локально для использования другими примерами. На сегодняшний день мы сохраняем содержимое этих наборов данных в git, даже если это может быть плохой идеей, чтобы все примеры были легко запускаемыми. Позже мы посмотрим, предпочтём ли мы подход с "исключением о недостающей зависимости".
