# Настройки и окружение

Все настройки, которые можно найти в модуле `bonobo.settings`. Вы можете переопределить эти настройки, используя переменные окружения. Для ваших собственных настроек и значений конфигурации см. руководство [/guide/environment](../guide/environment.md).

## Debug

* **Назначение:** Устанавливает режим отладки, который более подробный. Уровень логирования будет снижен до DEBUG вместо INFO.
* **Окружение:** `DEBUG`
* **Настройка:** `bonobo.settings.DEBUG`
* **По умолчанию:** `False`

## Profile

* **Назначение:** Устанавливает профилирование, которое добавляет вывод использования памяти/CPU. Ещё не полностью реализовано. Ожидается, что установка этого значения в true приведёт к значительному влиянию на производительность.
* **Окружение:** `PROFILE`
* **Настройка:** `bonobo.settings.PROFILE`
* **По умолчанию:** `False`

## Quiet

* **Назначение:** Устанавливает тихий режим, который требует, чтобы любой вывод был распознаём компьютером. Форматирование будет удалено, но это позволит использовать unix-каналы и т.д. Ещё не полностью реализовано, несколько преобразований уже используют его. Вероятно, это должно быть по умолчанию на неинтерактивных терминалах.
* **Окружение:** `QUIET`
* **Настройка:** `bonobo.settings.QUIET`
* **По умолчанию:** `False`

## Logging Level

* **Назначение:** Устанавливает минимальный уровень логирования Python.
* **Окружение:** `LOGGING_LEVEL`
* **Настройка:** `bonobo.settings.LOGGING_LEVEL`
* **По умолчанию:** `DEBUG`, если DEBUG False, иначе `INFO`
* **Значения:** `CRITICAL`, `FATAL`, `ERROR`, `WARNING`, `INFO`, `DEBUG`, `NOTSET`

## I/O Format

* **Назначение:** Устанавливает формат ввода/вывода по умолчанию для встроенных преобразований. Может быть переопределён на каждом узле. Значение `kwargs` означает, что каждый узел будет пытаться читать свой ввод из именованных аргументов (и писать вывод в аналогичном формате), в то время как `arg0` означает, что он будет пытаться читать свой ввод из первого позиционного аргумента (и писать вывод в аналогичном формате).
* **Окружение:** `IOFORMAT`
* **Настройка:** `bonobo.settings.IOFORMAT`
* **По умолчанию:** `kwargs`
* **Значения:** `kwargs`, `arg0`
