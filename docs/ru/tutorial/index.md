# Первые шаги

Bonobo — это ETL-фреймворк (Extract-Transform-Load) для Python 3.5. Цель состоит в том, чтобы определить преобразования данных с помощью Python-кода, отвечающего за обработку похожих независимых строк данных.

Bonobo **не является** статистическим инструментом или инструментом для науки о данных. Если вы ищете инструмент анализа данных в Python, используйте Pandas.

Bonobo — это сборочная линия бережливого производства для данных, которая позволяет вам сосредоточиться на реальной работе, а не на сантехнике (контексты выполнения, параллелизм, обработка ошибок, вывод в консоль, логирование и т.д.).

Bonobo использует простой Python и должен быть быстрым и лёгким для изучения.

## Вы не одни!

Хорошую документацию писать непросто.

Хотя весь контент здесь должен быть точным, вы можете почувствовать недостаток полноты, в чём мы признаёмся и приносим извинения.

Если вы застряли, пожалуйста, приходите в [Bonobo Slack Channel](https://bonobo-slack.herokuapp.com/), и мы разберёмся.

Если вы не застряли, но у вас были трудности с пониманием чего-либо, пожалуйста, рассмотрите возможность внести вклад в документацию (используя pull-запросы на GitHub).
