# Часть 4: Сервисы

Все внешние зависимости (такие как файловые системы, сетевые клиенты, подключения к базам данных и т.д.) должны быть предоставлены преобразованиям как сервис. Это позволит обеспечить большую гибкость, включая возможность тестировать ваши преобразования изолированно от внешнего мира и легко переключаться на продакшн (быть удобным для людей в системном администрировании).

В последнем разделе мы использовали сервис `fs` для доступа к файловым системам, мы пойдём ещё дальше, переключив наш вызов `requests` на использование сервиса `http`, чтобы мы могли переключить сессию `requests` во время выполнения. Мы будем использовать её для добавления http-кэша, что отлично подходит, чтобы не перегружать удалённый API.

## Сервисы по умолчанию

По умолчанию |bonobo| предоставляет только два сервиса:

* `fs`, объект :obj:`fs.osfs.OSFS` для доступа к файлам.
* `http`, объект :obj:`requests.Session` для доступа к Web.

## Переопределение сервисов

Вы можете переопределить сервисы по умолчанию или определить свои собственные сервисы, предоставив словарь аргументу `services=` :obj:`bonobo.run`. Сначала давайте перепишем get_services:

```python
import requests

def get_services():
    http = requests.Session()
    http.headers = {'User-Agent': 'Monkeys!'}
    return {
        'http': http
    }
```

## Переключение requests на использование сервиса

Давайте заменим вызов :obj:`requests.get`, который мы использовали на первых этапах, на использование сервиса `http`:

```python
from bonobo.config import use

@use('http')
def extract_fablabs(http):
    yield from http.get(FABLABS_API_URL).json().get('records')
```

Тада, готово! Вы больше не привязаны к конкретной реализации, а к любому объекту, совместимому с :obj:`requests`, который пользователь хочет предоставить.

## Добавление кэша

Давайте продемонстрируем гибкость этого подхода, добавив некоторый локальный кэш для HTTP-запросов, чтобы не перегружать конечную точку API во время запуска наших тестов.

Сначала давайте установим `requests-cache`:

```shell
$ pip install requests-cache
```

Затем давайте переключим реализацию условно.

```python
def get_services(use_cache=False):
    if use_cache:
        from requests_cache import CachedSession
        http = CachedSession('http.cache')
    else:
        import requests
        http = requests.Session()

    return {
        'http': http
    }
```

Затем в основном блоке давайте добавим поддержку аргумента `--use-cache`:

```python
if __name__ == '__main__':
    parser = bonobo.get_argument_parser()
    parser.add_argument('--use-cache', action='store_true', default=False)

    with bonobo.parse_args(parser) as options:
        bonobo.run(get_graph(**options), services=get_services(**options))
```

И вы готовы! Теперь вы можете переключаться между использованием кэша или нет, используя аргумент `--use-cache` в командной строке при запуске вашего задания.
