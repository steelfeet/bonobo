# История

|bonobo| — это полная переработка **rdc.etl**, нацеленная на современные версии Python (3.5+).

**rdc.etl** — это теперь устаревшая библиотека ETL для Python 2.7+, разработка которой началась в 2012 году, и была открыта в 2013 году (см. `первый коммит <https://github.com/rdcli/rdc.etl/commit/fdbc11c0ee7f6b97322693bd0051d63677b06a93>`_).

Хотя первый коммит в |bonobo| произошёл в конце 2016 года, он основан на большом количестве кода, знаний и опыта, которые появились благодаря **rdc.etl**.

Было бы контрпродуктивно переносить ту же кодовую базу:

* многие ошибки невозможно было исправить обратно совместимым способом (например, преобразования были с состоянием, что делало их более сложными для написания и невозможными для повторного использования, много усилий было потрачено на то, чтобы компоненты имели несколько входов и несколько выходов, хотя в 99% случаев это бесполезно, и т.д.).
* мы также хотели разработать что-то, что использует преимущества современных версий Python, отсюда и выбор 3.5+.

**rdc.etl** по-прежнему выполняет задания по преобразованию данных, как в Python 2.7, так и в 3, и мы повторно используем всё, что возможно, для продолжения построения |bonobo|.
