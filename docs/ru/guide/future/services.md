## Будущее и предложения

Это первая реализация, и она будет развиваться. Однако базовые концепции останутся теми же.

Может произойти или нет, в зависимости от обсуждений.

* Внедрение на основе синглтона или прототипа (используя терминологию Spring, см.
  https://www.tutorialspoint.com/spring/spring_bean_scopes.htm), позволяющее умное использование фабрик и эффективное совместное использование ресурсов.
* Лениво разрешаемые параметры, в конечном итоге переопределяемые через командную строку или окружение, чтобы вы могли, например, переопределить DSN базы данных или целевую файловую систему в командной строке (или с помощью переменных оболочки).
* Блокировки на основе пула, которые гарантируют, что только одна (или n) трансформаций используют данный сервис одновременно.
* Простая реализация конфигурации, использующая файл python для конфигурации (например: bonobo run ... --services=services_prod.py).
* Конфигурация по умолчанию для сервисов, используя необязаемый вызываемый объект (`def get_services(args): ...`). Возможно, привязать конфигурацию по умолчанию к графу, но я не большой фанат, потому что это не связано с логикой графа.
* Реализация по умолчанию для сервиса в трансформации или в дескрипторе. Возможно, не самая хорошая идея, потому что это склонно продвигать вперёд несколько экземпляров одного и того же, но, может быть...

  Несколько идей о том, как это можно реализовать с точки зрения пользователя.

  .. code-block:: python

      # использование вызова
      http = Service('http.client')(requests)

      # использование более явного вызова
      http = Service('http.client').set_default_impl(requests)

      # использование декоратора
      @Service('http.client')
      def http(self, services):
          import requests
          return requests

      # как значение по умолчанию в подклассе Service
      class HttpService(Service):
          def get_default_impl(self, services):
              import requests
              return requests

      # ... затем используйте его как другой сервис
      http = HttpService('http.client')


Это находится в разработке, дайте нам знать, что вы думаете (slack может быть хорошим местом для этого).
Основы уже работают, и вы можете попробовать.
