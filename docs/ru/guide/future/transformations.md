## Вывод

Давайте посмотрим на правила (первое совпадение побеждает).

1. Флаг, за которым возможно следует что-то ещё, отмечает специальное поведение. Если это поддерживается, оставшаяся часть строки вывода будет интерпретироваться с использованием тех же правил, и некоторые флаги могут быть объединены.

   **NOT_MODIFIED**

   **NOT_MODIFIED** сообщает bonobo использовать входную строку без изменений как вывод.

   *НЕ МОЖЕТ быть объединён*

   Пример:

   .. code-block:: python

       from bonobo import NOT_MODIFIED

       def output_will_be_same_as_input(*args, **kwargs):
           yield NOT_MODIFIED

2. После того как все флаги "потреблены", оставшаяся часть интерпретируется.

   * Если это экземпляр :class:`bonobo.Bag`, то он используется напрямую.
   * Если это :class:`dict`, то будет создан :class:`bonobo.Bag` только с kwargs.
   * Если это :class:`tuple`, то будет создан :class:`bonobo.Bag` только с args, если только его последний аргумент не является :class:`dict`, в этом случае будет создан :class:`bonobo.Bag` с args+kwargs.
   * Если это что-то ещё, это будет использовано для создания :class:`bonobo.Bag` только с одним аргументом.

   **APPEND**

   **APPEND** сообщает bonobo добавить этот вывод к вводу (позиционные аргументы будут равны `input_args + output_args`, именованные аргументы будут равны `{**input_kwargs, **output_kwargs}`).

   *МОЖЕТ быть объединён, но не с самим собой*

   .. code-block:: python

       from bonobo import APPEND

       def output_will_be_appended_to_input(*args, **kwargs):
           yield APPEND, 'foo', 'bar', {'eat_at': 'joe'}

   **LOOPBACK**

   **LOOPBACK** сообщает bonobo, что этот вывод должен быть возвращён в нашу собственную очередь ввода, что позволяет создать версию обработки потока рекурсивных алгоритмов.

   *МОЖЕТ быть объединён, но не с самим собой*

   .. code-block:: python

       from bonobo import LOOPBACK

       def output_will_be_sent_to_self(*args, **kwargs):
           yield LOOPBACK, 'Hello, I am the future "you".'

   **CHANNEL(...)**

   **CHANNEL(...)** сообщает bonobo, что этот вывод не использует канал по умолчанию и маршрутизируется через другой путь.
   Это то, что вы, вероятно, не должны использовать, если только ваш дизайн потока данных не является сложным, и если вы не уверены в этом, это, вероятно, означает, что это не та функция, которую вы ищете.

   *МОЖЕТ быть объединён, но не с самим собой*

   .. code-block:: python

      from bonobo import CHANNEL

      def output_will_be_sent_to_self(*args, **kwargs):
          yield CHANNEL("errors"), 'That is not cool.'
